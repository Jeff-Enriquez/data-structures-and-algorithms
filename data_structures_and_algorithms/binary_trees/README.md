# DFS Comparison Summary

| Traversal | Visit Order | Key Use Case |
|-----------|-------------|--------------|
| Preorder | Root → Left → Right | Tree cloning, serialization, prefix expressions |
| Inorder | Left → Root → Right | Sorting BSTs, in-fix expressions, k-th smallest element |
| Postorder | Left → Right → Root | Tree deletion, height calculation, postfix expressions |
